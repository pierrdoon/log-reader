# Log Reader

Мощное десктопное приложение для просмотра и анализа лог-файлов с поддержкой локальных и удаленных файлов через SSH. Построено на Electron, React и TypeScript.

## 📋 Описание

Log Reader — это современное приложение для работы с лог-файлами любого размера. Оно позволяет эффективно просматривать как локальные файлы, так и файлы на удаленных серверах через SSH-подключение. Приложение использует потоковое чтение файлов, что позволяет работать с файлами размером в сотни мегабайт без загрузки всего содержимого в память.

### Основные возможности

- 📁 **Локальные файлы**: Просмотр лог-файлов с локального диска
- 🔐 **SSH подключение**: Чтение файлов с удаленных серверов через SSH/SFTP
- 📊 **Потоковое чтение**: Эффективная работа с большими файлами (16MB, 200MB+)
- 📈 **Прогресс-бар**: Визуализация процесса загрузки больших файлов
- 🔄 **Ленивая загрузка**: Загрузка файла порциями по мере прокрутки
- 🎯 **Быстрая навигация**: Мгновенный переход к нужным строкам
- 💾 **Энергоэффективность**: Оптимизировано для работы с большими файлами без блокировки UI

## 📖 Использование

### Работа с локальными файлами

1. Нажмите кнопку **"Open Folder"** в сайдбаре
2. Выберите директорию с лог-файлами
3. Кликните на файл для просмотра

### Подключение по SSH

1. Нажмите кнопку **"Connect via SSH"** в сайдбаре
2. Заполните форму подключения:
   - **Host**: Адрес сервера (например, `example.com`)
   - **Port**: Порт SSH (по умолчанию 22)
   - **Username**: Имя пользователя
   - **Password**: Пароль (или оставьте пустым, если используете ключ)
   - **Private Key**: Приватный SSH ключ (опционально)
   - **Passphrase**: Парольная фраза для ключа (если ключ зашифрован)
   - **Remote Path**: Путь на удаленном сервере (например, `/var/log`)
3. Нажмите **"Connect"**
4. После подключения вы увидите файлы и директории на удаленном сервере
5. Кликните на файл для просмотра

### Просмотр файлов

- Файлы загружаются порциями по 500 строк
- При прокрутке вниз автоматически загружаются следующие порции
- Для больших файлов отображается прогресс-бар с информацией о загрузке
- В заголовке показывается количество загруженных строк

### Основные компоненты

#### SSH Manager (`src/main/ssh-manager.ts`)

Управляет SSH подключениями и потоковым чтением файлов:

- **Переиспользование SFTP сессий**: Одна SFTP сессия на подключение для эффективности
- **Потоковое чтение**: Использует `createReadStream` для чтения больших файлов
- **Управление потоками**: Ограничение на 3 одновременных потока
- **Таймауты с продлением**: Автоматическое продление таймаута при активности
- **Отслеживание прогресса**: Отправка событий прогресса в UI

#### Log Viewer (`src/renderer/src/components/LogViewer.tsx`)

Компонент для отображения лог-файлов:

- **Ленивая загрузка**: Загрузка по 500 строк за раз
- **Автопрокрутка**: Автоматическая загрузка при прокрутке
- **Прогресс-бар**: Визуализация загрузки для SSH файлов
- **Обработка ошибок**: Понятные сообщения об ошибках

## 🔧 Технические детали

### Потоковое чтение файлов

Приложение использует потоковое чтение для работы с большими файлами:

- **Локальные файлы**: `fs.createReadStream` с `readline` интерфейсом
- **SSH файлы**: `sftp.createReadStream` с буфером 256KB
- **Построчная обработка**: Файлы читаются построчно без загрузки в память
- **Досрочное завершение**: Чтение останавливается при достижении нужного количества строк

### SSH подключение

- **SFTP протокол**: Используется для передачи файлов
- **Переиспользование сессий**: Одна SFTP сессия на подключение
- **Управление ресурсами**: Автоматическая очистка потоков и сессий
- **Обработка ошибок**: Детальное логирование и обработка ошибок

### Производительность

- **Буферизация**: 256KB буфер для SSH потоков
- **Ленивая загрузка**: Загрузка только видимых строк
- **Оптимизация памяти**: Файлы не загружаются полностью в память
- **Асинхронная обработка**: Все операции не блокируют UI

## 📝 Особенности реализации

### Управление SSH подключениями

- Подключения хранятся в `Map` с уникальными ID
- SFTP сессии переиспользуются для всех операций с файлами
- Активные потоки отслеживаются для предотвращения утечек памяти
- Автоматическое закрытие при отключении

### Обработка больших файлов

- Таймаут 5 минут с автоматическим продлением при активности
- Прогресс отслеживается по полученным байтам
- События прогресса отправляются в UI через IPC
- Оптимизированное логирование (не спамит консоль)

### Безопасность

- Пароли и ключи не сохраняются
- SSH подключения закрываются при отключении
- Контекстная изоляция включена
- Безопасная передача данных через IPC

## 🐛 Отладка

### Логирование

Приложение использует подробное логирование с префиксом `[SSH]`:

- Начало и завершение операций
- Прогресс чтения файлов
- Ошибки и предупреждения
- Состояние подключений

Логи можно увидеть в:
- Консоли разработчика (DevTools)
- Терминале, где запущено приложение

### Типичные проблемы

**Проблема**: Таймаут при чтении больших файлов
- **Решение**: Таймаут автоматически продлевается при активности потока

**Проблема**: "Channel open failure"
- **Решение**: Используется переиспользование SFTP сессий, ограничение на одновременные потоки

**Проблема**: Медленная загрузка
- **Решение**: Используется буферизация 256KB, оптимизировано для больших файлов
